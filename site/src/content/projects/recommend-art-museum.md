## Overview

Recommend Art Museum is a web application I developed to explore painting recommendations using machine learning. The application presents recommended artworks with their titles, artists, and associated museums.

## Features

- **Art → Art:** Recommends paintings based on an input artwork.
- **Scene → Art:** Recommends paintings based on an input photograph.

The results interface displays the ten highest- and lowest-ranked recommendations, including artwork images, metadata, and links to museums.

## Development

I developed the web application using Python and Flask and deployed the original prototypes on Heroku.
