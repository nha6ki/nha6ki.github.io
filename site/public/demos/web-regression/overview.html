Web アプリの回帰テスト

6つのアプリを対象に、日常業務で使う操作と保存結果を19件の回帰テストで確認しました。

WordPressでお知らせを公開する

WordPressは、Webサイトの記事を作成・公開するアプリです。編集者はお知らせを下書きとして準備し、公開後に受付時間などの記載を訂正することもできます。

3件の検査では、編集者が読める下書きが未ログインの読者には見えないか、投稿一覧から公開すると読者が日本語のお知らせを読めるか、受付開始を午前9時から10時に訂正すると同じURLに新しい時刻だけが表示されるかを確かめます。

Vikunjaで日々のタスクを管理する

Vikunjaは、仕事をプロジェクトごとに整理するアプリです。たとえば「月次報告の資料を確認」というタスクを登録し、作業が済んだら完了にします。

4件の検査では、日本語の件名と登録先が正しいか、再読み込み後も完了状態が続くか、件名が空のときにタスクが増えないか、別のプロジェクトに同名のタスクがあっても選んだ1件だけが完了するかを確かめます。

Gristで請求明細を管理する

Gristは、表の各行にデータを記録し、数式で計算できるアプリです。このデモでは、請求書の品目ごとに数量と単価を入力し、その積を明細金額として表示します。

3件の検査では、単価2,500の品目の数量を2から3に変えると金額が7,500になるか、日本語の品目名を訂正しても明細のIDと金額が保たれるか、1行を削除しても別の明細が残るかを確かめます。

Paperless-ngxで文書を整理する

Paperless-ngxは、請求書や納品書などを取り込み、取引先やタグを付けて整理するアプリです。たとえば、確認が必要な文書に「要確認」タグを付けると、あとからその文書だけを一覧にできます。

3件の検査では、取り込んだPDFとダウンロードした原本がバイト単位で一致するか、設定した取引先とタグが保存されるか、「要確認」で絞り込むと対象の納品書だけが表示されるかを確かめます。

Giteaで開発課題を管理する

Giteaは、開発チームがソースコードと開発課題を管理するアプリです。不具合や改善要望を「Issue」として記録し、対応が終わったらそのIssueを閉じます。

3件の検査では、日本語で登録した件名と本文が保存されるか、件名を変更した後も検索して同じIssueを閉じられるか、非公開のIssueを閲覧できる人が権限どおりかを確かめます。

Snipe-ITでPCの貸出と返却を管理する

Snipe-ITは、組織の機器を1台ずつ台帳に登録し、誰に貸し出しているかを記録するアプリです。同じ機種のPCが複数あっても、それぞれの資産IDで区別できます。

3件の検査では、貸し出したPCに指定した利用者が記録されるか、返却後にそのPCの貸出先が空になるか、同型のPCを2台用意して片方を貸し出したときにもう片方が未割当のままかを確かめます。
